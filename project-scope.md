# Project Scope: Painting Service Application

## Overview
This project is a web-based platform for managing painting services. The application provides customers with an easy way to browse services, schedule appointments, post reviews, and manage their painting needs. Admins can upload images, manage appointments, provide estimates


## Features
### Core Functionality
1. **Homepage** - Introduction to the painting service platform and links to other pages and display images uploaded by Admin
2. **Services Page** - Detailed listing of painting services offered such as    
   - Interior painting
   - Exterior painting
   - Touch-up work
   - Specialized finishes
3. **Schedule Page** - Appointment booking system with date/time selection
4. **About Page** - Company information and contact details
5. **Navigation** - Consistent header navigation across all pages
6. **Photo Gallery** - Display uploaded pictures on a home page as a separate section
7. **Upload Images** - Provide ability to upload images by admin. This page should be secured by a static user name and password
8. **Reviews** - Provide a section for submitting customer reviews and display the ratings on home page
